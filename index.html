💾 Copia de seguridad ▲
Un solo archivo con TODO lo tuyo: las canciones que agregaste, tus ediciones a las originales y tus listas. Si algo se pierde o se pisa, lo restaurás en un minuto.
🎹 Pedal o teclado (modo en vivo) ▼
Un pedal Bluetooth que funcione como teclado (los de "pasar páginas") puede pasar de canción y cambiar el tono sin soltar el instrumento. Asignale a cada acción la tecla que manda tu pedal.
Probador: pisá el pedal (o apretá una tecla) y acá aparece lo que recibe la app. Si no aparece nada, ese pedal no manda teclas.
☁️ Sincronizar entre dispositivos ▼
Esta app ya viene conectada de fábrica a la base de datos del equipo — cualquier canción que agregues o edites desde cualquier lugar se guarda ahí sola, sin que tengas que hacer nada. Este panel es solo para uso avanzado (por ejemplo, si alguna vez querés apuntar a otra base propia, o desconectarte).
create table if not exists cancionero_kv ( key text primary key, value jsonb, updated_at timestamptz default now() ); alter table cancionero_kv enable row level security; create policy "allow all" on cancionero_kv for all using (true) with check (true);
Sin conectar — tus canciones se guardan solo en este navegador.

🎸 Afinador — escuchá las notas ▼
Las 6 cuerdas de la guitarra criolla, afinación estándar. Tocá una: suena un tono sostenido (no se apaga solo) para que lo compares tranquilo contra tu cuerda. Tocá la misma de nuevo (o otra) para pararlo.
